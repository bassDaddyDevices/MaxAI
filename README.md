# MaxAI

## Overview
MaxAI is a project that explores the intersection of AI and the Max/MSP environment. This project aims to enhance the capabilities of AI in handling visual programming tasks, particularly within the Max/MSP ecosystem.

## Key Features

- **AI Coding Assistance:**
 - AI can assist with writing codebox code and genExpr scripts, though it's recommended to double-check with reference documentation.
 - AI excels at handling JavaScript-based tasks, including JSUi and V8UI.

- **Visual Programming Challenges:**
 - AI struggles with understanding and executing visual patches.
 - Best practices include breaking down patches into sections or starting from scratch.

- **Alternative Tools:**
 - Claude is preferred for conversational programming, offering a more intuitive approach compared to the current AI capabilities.

- **API Integration:**
 - An API point is available for AI to generate JavaScript commands, enabling the creation of patches.
