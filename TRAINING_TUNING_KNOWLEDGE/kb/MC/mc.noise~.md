# mc.noise~

Generate white noise (multichannel)

## Description

Use the [noise~](https://docs.cycling74.com/reference/noise~) object to generate a signal consisting of uniformly distributed random white-noise with values between -1.0 and 1.0.

## Arguments

None.

Shared across all objects — see [Multichannel Group Messages](../_shared/mc-group-messages.md).

## Output

### signal

The [noise~](https://docs.cycling74.com/reference/noise~) object generates a signal consisting of uniformly distributed random white-noise values between -1 and 1.
