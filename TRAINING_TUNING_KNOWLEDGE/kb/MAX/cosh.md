# cosh

Hyperbolic cosine function

## Description

Use the [cosh](https://docs.cycling74.com/reference/cosh) object to calculate and output the hyperbolic cosine of any given number.

## Arguments

### initial-value[float or int] optional

Sets the initial value for the hyperbolic cosine function.

## Attributes

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Messages

### bang

Calculates the hyperbolic cosine of the number currently stored. If there is no argument, [cosh](https://docs.cycling74.com/reference/cosh) initially holds  0 .

### int

Input to the hyperbolic cosine function

Arguments:

- input
  [int]

### float

Input to the hyperbolic cosine function

Arguments:

- input
  [float]

## Output

### float

The hyperbolic cosine of the input.

### int

The hyperbolic cosine of the input.
