# osc.packet

Store and recall an OSC packet

## Description

The [osc.packet](https://docs.cycling74.com/reference/osc.packet) object stores and recalls OSC packets, and can convert them into different formats.

## Arguments

None.

## Attributes

### outputformat[symbol]: osc\_packet

Set the output format an OSC packet will be converted to.

Possible values:

'osc\_packet'

'fullpacket'
