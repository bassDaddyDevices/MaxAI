# thispoly~

Control [poly~](https://docs.cycling74.com/reference/poly~) voice allocation and muting

## Description

Use the [thispoly~](https://docs.cycling74.com/reference/thispoly~) object to control [poly~](https://docs.cycling74.com/reference/poly~) voice allocation and muting. When placed inside a patcher loaded by the [poly~](https://docs.cycling74.com/reference/poly~) object, it sends and receives messages from the [poly~](https://docs.cycling74.com/reference/poly~) object that loads it.

## Arguments

None.

## Attributes

### automute[int]: 0

Automatic Voice Muting

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Messages

### bang

Reports the instance number of the patch. The first instance is reported as  1 .

### int

Toggles the "busy" state for the patcher instance when the message  busy 1  is received. The object will not receive messages generated by a  note  or  midinote  message to the left inlet of the parent [poly~](https://docs.cycling74.com/reference/poly~) object when the "busy" state is on.

Arguments:

- busy-state
  [int]

### mute

Disables DSP processing for the loaded instance of the patcher when the message  mute 1  is received. This message can be combined with an  int  message which toggles the "busy" state of the patcher to create voices in a patcher which are only on while they play a "note".

Arguments:

- mute-flag
  [int]

### signal

Sets the "busy" state of the patcher instance. The busy state for the patcher instance is set to 1 when the [thispoly~](https://docs.cycling74.com/reference/thispoly~) object receives a non-zero input signal. The busy state is set to 0 otherwise.

## Output

### instance

Out left outlet: The instance number, starting at  1 , reported when [thispoly~](https://docs.cycling74.com/reference/thispoly~) receives the  bang  message. If the patcher containing [thispoly~](https://docs.cycling74.com/reference/thispoly~) was not loaded within a [poly~](https://docs.cycling74.com/reference/poly~) object,  0  is output.

### mute

Out middle outlet: If the loaded instance of the patcher is muted, a  1  is output. If the instance is not muted, a  0  is output.

### voice count

Out right outlet: The total [poly~](https://docs.cycling74.com/reference/poly~) voice count, reported when [thispoly~](https://docs.cycling74.com/reference/thispoly~) receives the  bang  message. If the patcher containing [thispoly~](https://docs.cycling74.com/reference/thispoly~) was not loaded within a [poly~](https://docs.cycling74.com/reference/poly~) object,  1  is output.
