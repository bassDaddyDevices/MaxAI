# asinh~

Signal hyperbolic arc-sine function

## Description

Use the [asinh~](https://docs.cycling74.com/reference/asinh~) object to calculate and output a signal that is the hyperbolic arc-sine function of each sample of the input signal.

## Arguments

None.

## Attributes

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Messages

### signal

Input to hyperbolic arc-sine function

## Output

### signal

The hyperbolic arc-sine of the input in radians.
