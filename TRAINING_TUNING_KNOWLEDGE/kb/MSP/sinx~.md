# sinx~

Signal sine function

## Description

[sinx~](https://docs.cycling74.com/reference/sinx~) is a real sine function whose input expects values between 0 and 2π (similar to [cosx~](https://docs.cycling74.com/reference/cosx~) but unlike [cos~](https://docs.cycling74.com/reference/cos~) which is designed to work with [phasor~](https://docs.cycling74.com/reference/phasor~) 's output from 0 to 1).

## Arguments

None.

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Messages

### signal

Input to sine function

## Output

### signal

The sine of the input.
