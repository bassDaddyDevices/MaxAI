# Slideshow folders in Jitter

To switch between folders of a [slideshow in jitter](http://music.arts.uci.edu/dobrian/COSMOS2005/slideshow.txt) ([explained here](http://music.arts.uci.edu/dobrian/COSMOS2005/slideshowexplanation.txt)) you can set the prefix or folder (i.e. the file path) of the **umenu** object with the *prefix* message, then clear and populate it.

## Objects used

`umenu`, `prepend`, `dropfile`
