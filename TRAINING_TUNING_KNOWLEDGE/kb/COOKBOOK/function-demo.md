# Function Demo

If you have wondered how to setup the **function** object to remember its settings upon opening there 3 things to note:

1. **preset** and **pattrstorage** can give you all kinds of possibilities on loadbang.

2. You can loadbang all kinds of settings to **function** (see example patch).

3. **Function** already stores its previous settings with the patch anyway. But if you want to ensure that function looks the same each time it’s opened, even if somebody makes changes to it and saves the changes, you can use option 1 or 2.

## Objects used

`loadbang`, `function`
