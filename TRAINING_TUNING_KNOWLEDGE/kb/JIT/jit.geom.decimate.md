# jit.geom.decimate

Decimate surface geometry

## Description

The [jit.geom.decimate](https://docs.cycling74.com/reference/jit.geom.decimate) geometry processing object performs a decimation operation on input surface, reducing the number of vertices and faces while retaining the overall shape.
