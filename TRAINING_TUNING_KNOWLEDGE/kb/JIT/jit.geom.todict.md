# jit.geom.todict

Convert geometry to a dictionary

## Description

The [jit.geom.todict](https://docs.cycling74.com/reference/jit.geom.todict) op converts Jitter half-edge geometry to a [dictionary](https://docs.cycling74.com/userguide/dictionaries) containing geometry mesh data.

## Attributes

### vertex\_dict[int]

Include vertex dictionary

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).
