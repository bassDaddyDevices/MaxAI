# jit.geom.prop

Add properties to half-edge geometry

## Description

Use [jit.geom.prop](https://docs.cycling74.com/reference/jit.geom.prop) to add certain properties to the half-edge geometry structure. Properties may be added to faces, vertices, halfedges, or edges, depending on their prop type.

## Attributes

### prop[symbol]

Property to add

Possible values:

'centroid'

'area'

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).
