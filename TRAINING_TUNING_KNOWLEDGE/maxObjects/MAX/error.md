# error

Report Max errors

## Description

Listens for and reports Max errors as message output. This will allow for error management in cases where it is not appropriate to display the Max window.

## Arguments

### on[int] optional

Turn on error reporting. If no argument is given, then error reporting will be off until an  int  message is received.

## Attributes

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Messages

### int

The [error](https://docs.cycling74.com/reference/error) object allows you to catch errors and output them as Max messages. A non-zero number starts the error object "listening" for Max errors. The [error](https://docs.cycling74.com/reference/error) object must be listening to produce any output. A  0  turns off listening.

Arguments:

- enable
  [int]

### float

Converted to  int .

Arguments:

- enable
  [float]

### error

The word  error  followed by any message will send that message out the outlet.

Arguments:

- message
  [list]

## Output

### symbol

Any Max error generated by any object in any patch while the [error](https://docs.cycling74.com/reference/error) object is listening is sent out the outlet preceded by the symbol  error . The messages are output as individual words so you can check for specific failures.

If you want to strip off the initial  error  message from the object's output, use a [route](https://docs.cycling74.com/reference/route) [error](https://docs.cycling74.com/reference/error) object. If you want to use the [error](https://docs.cycling74.com/reference/error) object's output as a message, put a [prepend](https://docs.cycling74.com/reference/prepend)  read  object between [route](https://docs.cycling74.com/reference/route) [error](https://docs.cycling74.com/reference/error) and the object that will process the error message.
