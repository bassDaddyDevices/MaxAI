# polymidiin

Output Multidimensional Polyphonic Expression (MPE) MIDI data

## Description

The [polymidiin](https://docs.cycling74.com/reference/polymidiin) object is used inside a  poly~  instance. It outputs MPE MIDI data.

## Arguments

None.

## Attributes

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Output

### list

MPE MIDI Messages.
