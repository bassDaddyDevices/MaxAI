# mc.tanh~

Signal hyperbolic tangent function (multichannel)

## Description

Use the [tanh~](https://docs.cycling74.com/reference/tanh~) object to calculate and output a signal that is the hyperbolic tangent function of each sample of the input signal.

## Arguments

None.

### Multichannel Group Messages

## Output

### signal
