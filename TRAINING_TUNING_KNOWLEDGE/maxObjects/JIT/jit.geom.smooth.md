# jit.geom.smooth

Smooth surface geometry

## Description

[jit.geom.smooth](https://docs.cycling74.com/reference/jit.geom.smooth) performs a smoothing operation on the input surface.

## Attributes

### iterations[int]

The number of smoothing iterations. The more, the smoother the surface will be.
