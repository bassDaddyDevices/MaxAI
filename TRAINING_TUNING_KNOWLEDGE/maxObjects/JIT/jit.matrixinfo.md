# jit.matrixinfo

Report matrix planecount, type, dimensions

## Description

[jit.matrix](https://docs.cycling74.com/reference/jit.matrix) reports a given matrix's planecount, type, and dim attributes in the form

 planecount   *number-of-planes*
 type   *data-type*
 dim   *dimension0* ...  *dimensionN* .

## Arguments

None.

## Attributes

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).
