# jit.geom.dimples

Dimples deformation on surface geometry

## Description

[jit.geom.dimples](https://docs.cycling74.com/reference/jit.geom.dimples) extrudes the center of each face to create a spiked surface.

## Attributes

### offset[float]

Controls the direction and extent of the resulting dimples/spikes.

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).
