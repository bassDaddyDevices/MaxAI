# sinh~

Signal hyperbolic sine function

## Description

Use the [sinh~](https://docs.cycling74.com/reference/sinh~) object to calculate and output a signal that is the hyperbolic sine function of each sample of the input signal.

## Arguments

None.

## Attributes

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Messages

### signal

Input to hyperbolic sine function

## Output

### signal

The hyperbolic sine of the input.
