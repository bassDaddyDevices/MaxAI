# atan~

Signal arc-tangent function

## Description

Use the [atan~](https://docs.cycling74.com/reference/atan~) object to calculate and output a signal that is the arc-tangent function of each sample of the input signal.

## Arguments

None.

## Attributes

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Messages

### signal

Input to arc-tangent function

## Output

### signal

The arc-tangent of the input.
