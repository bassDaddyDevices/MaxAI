# atanh~

Signal hyperbolic arc-tangent function

## Description

Use the [atanh~](https://docs.cycling74.com/reference/atanh~) object to calculate and output a signal that is the hyperbolic arc-tangent function of each sample of the input signal.

## Arguments

None.

## Attributes

### Common Box Attributes

Shared across all objects — see [Common Box Attributes](../_shared/common-box-attributes.md).

## Messages

### signal

Input to hyperbolic arc-tangent function

## Output

### signal

The hyperbolic arc-tangent of the input.
