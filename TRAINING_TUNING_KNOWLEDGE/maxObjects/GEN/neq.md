# neq

Not equal operator

## Description

Returns 1 if in1 does not equal in2, else returns zero.

## Constructors

- { arguments={value2}, inlets={value1} }

- { arguments={}, inlets={value1, value2} }

## Inlets

### value1[float]

input value 1

### value2[float]

input value 2
